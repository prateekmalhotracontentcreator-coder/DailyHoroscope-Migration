### `4e54bad` -- Lagna Kundali Generate D1 Crash Fix

**Root cause (definitive):**
1. `LagnaKundaliComputeRequest` has `model_config = ConfigDict(extra="forbid")`
2. Frontend `handleCompute` was spreading `...form` which includes `city_slug` (UI-only field)
3. FastAPI returned 422 Unprocessable Entity with `detail` as **array of error objects**
4. `setError(arrayOfObjects)` stored the array
5. React threw rendering `<p>{[{type:"extra_forbidden",...}]}</p>` -- objects are not valid React children → white page crash

**Fix:**
- `handleCompute` + `handleSave`: explicit payload whitelist (8 fields only) -- `city_slug` stripped
- Error handler hardened: `typeof detail === "string" ? detail : detail?.[0]?.msg || fallback`

## Key Architecture Notes

### Premium Gate Pattern (new -- use for all new premium pages)
```jsx
// Inline on auth-aware pages (KP, Strategist, Tarot, Numerology, Palmistry, Lumina):
if (user && !user.is_premium) return <PremiumGateCard feature="..." description="..." />;

// Route-level via App.js:
<Route path="/..." element={<PremiumRoute feature="..." description="..."><Page /></PremiumRoute>} />
```

### Payload Hygiene Rule (new -- never spread form state into API calls)
```js
// BAD -- spreads UI-only fields (city_slug, etc.) into backend models with extra="forbid"
const payload = { ...form, ... };

// GOOD -- always whitelist explicit fields
const payload = { date: form.date, time: form.time, ... };
```

### Error Handler Rule (new)
```js
// FastAPI 422 detail is an array -- always guard:
const detail = err?.response?.data?.detail;
setError(typeof detail === "string" ? detail : detail?.[0]?.msg || "fallback message");
```
